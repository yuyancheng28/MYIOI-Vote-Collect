快速说明

本页把每个投票记录为仓库中的一个 Issue；投票以 Issue 评论的形式记录（格式 /vote 1）。
投票方式：
  1. 管理员登录（一次性）并创建投票；
  2. 成员打开页面并使用 个人 GitHub Token 登录以投票（也可由管理员代投）；
  3. 系统会根据 GitHub 用户名防止重复投票；
安全建议：不要把你的长期全权限 Token 粘贴到公共电脑。建议使用短期或最小 scope 的 token（repo:issues）。
